# Project brief

## One-line description

A reproducible 90-day marketing-intelligence study that reconstructs and codes publicly reported Indian brand activity across channels, funnel stages, cultural moments, talent usage and AI/data-led execution.

## Portfolio positioning

This project is intentionally different from a standard downloaded sales dataset. The core contribution is the **construction of a structured analytical dataset from fragmented public marketing evidence**, followed by reproducible marketing metrics and interpretation.

## Core research questions

1. Which broad sectors in the observed sample rely most on named celebrities or creators?
2. How often are campaigns attached to festivals, awareness days, sports moments or other occasions?
3. Which marketing actions are explicitly localized by city or region?
4. Where is AI/data part of actual marketing execution rather than merely a topic?
5. How is observed activity distributed across awareness, consideration, conversion, engagement and strategy?
6. How concentrated are sector-level channel choices?
7. Which sectors exhibit the greatest diversity of coded creative strategies?

## Suggested resume bullets

- Built a 90-day public-source marketing-intelligence dataset covering 91 Indian brand actions across 23 variables, including campaign objective, channel, celebrity/creator use, occasion context, localization, AI/data usage and funnel stage.
- Developed reproducible marketing metrics for celebrity dependency, occasion intensity, channel concentration (HHI) and creative-strategy diversity; automated validation and analysis with Python and GitHub Actions.
